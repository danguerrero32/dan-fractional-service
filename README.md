# Pide el deseo — Landing Dan Guerrero · Keen Impact LLC

Landing de venta single-file para el servicio de implementación de sistemas con IA de Dan Guerrero bajo Keen Impact LLC.

## Quickstart

Abre `Pide el deseo - Dan Guerrero.html` en cualquier navegador moderno. No requiere build, ni servidor, ni dependencias locales — solo conexión a Google Fonts.

## Stack

- HTML5 + CSS3 vanilla (sin frameworks)
- Tipografía: Cormorant Garamond + Manrope (Google Fonts)
- JS mínimo inline: scroll suave + año dinámico

## Variables clave

```css
--ink:       #000000
--paper:     #ffffff
--gold:      rgb(211, 202, 147)
--gold-deep: rgb(178, 165, 108)
```
